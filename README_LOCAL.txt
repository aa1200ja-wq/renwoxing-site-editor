Renwoxing local Supabase storage test
=====================================

GitHub main version:
9084a6ef573ce88b1dcc22ac71caba4442c3e3cc

Includes:
- Official website
- Editor
- Supabase draft storage
- Publish storage
- Local assets
- Automatic free-port launcher

How to test:
1. Extract this ZIP.
2. Double-click START_LOCAL.bat.
3. Open /editor.
4. Make a small test edit.
5. Click "儲存草稿".
6. The first save asks for the editor storage token.
7. Refresh /editor: the saved draft should reload.
8. Click "儲存並發布" only when you want /site to use the editor project.

Important:
- "儲存草稿" does NOT change the official website.
- "儲存並發布" DOES update the published project.
- The editor token is NOT stored in this ZIP or GitHub.
- Local port is automatically selected and is not fixed to 3000.
