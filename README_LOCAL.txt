Renwoxing GitHub local inspection package
=========================================

GitHub main version packaged:
65cf9e948d99993e280f41528b0d71f9e8ef997b
Short SHA: 65cf9e9

This ZIP contains the complete source snapshot from that commit:
- Official website
- Website editor
- public/assets images
- Next.js / React source and project configuration

Run on Windows:
1. Extract the ZIP to a normal folder.
2. Double-click START_LOCAL.bat.
3. On first run it installs npm packages.
4. Windows automatically selects an unused local port.
5. It opens both:
   /site   = official website
   /editor = editor

The port is NOT fixed to 3000.

This package does not deploy Vercel and does not modify GitHub when you run it locally.
